# marcdonatomeri.github.io

Interactive portfolio of **Marc Donato Merí**, a Data Science student at the UPV.

👉 **https://marcdonatomeri.github.io/**

A single-page site built with Three.js and GSAP. The point cloud in the hero is the real dataset from [SoundScope](https://github.com/marcdonatomeri/soundscope): 18,153 songs projected into 3D with PCA and grouped with K-Means.
